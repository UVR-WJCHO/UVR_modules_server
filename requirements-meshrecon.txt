# main_meshrecon_comm.py — capture, reconstruct, align, combine
#
# Traced from the import chain, not guessed:
#   main_meshrecon_comm -> modules_mesh    -> meshrecon/trellis (TRELLIS)
#                       -> modules_hotrack -> hotrack + segmentor/sam2_realtime
#                       -> modules_segment -> sam2_realtime, pycocotools
#                       -> modules_jointtrack -> meshalignment (nvdiffrast)
#                       -> metaobj_wrapper/combine_rocket_glb
#   plus _comm/hl2_data_pb2 for the wire format.
#
# Verified against uvr_integ (RTX 5090, CUDA 12.8, Python 3.10), where every
# module above imports and TRELLIS reports "[SPARSE] Backend: spconv,
# Attention: xformers".
#
#   conda create -n uvr_meshrecon python=3.10 && conda activate uvr_meshrecon
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#   pip install -r requirements-meshrecon.txt
#   # then the three that pip cannot resolve — see NOT INSTALLABLE FROM PyPI below
#
# torch is deliberately NOT pinned here: the wheel has to match your CUDA
# toolkit, so install it first from the right index. 2.7.0+cu128 is what this
# was verified on. spconv is CUDA-versioned too (spconv-cu120 for CUDA 12.x).
